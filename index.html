Quickstart Deployment

Launch the R Shiny visualization portal locally with a single command.

R Console R v4.2+ 
# Install required packages for data processing and interactive charts
install.packages(c("shiny", "tidyverse", "plotly", "shinydashboard", "dtplyr"))

# Run the digital phenotyping app directly from your GitHub repository
shiny::runGitHub(
  repo = "digital-phenotyping-shiny", 
  username = "your-github-username"
)
